PROJECT

项目定位

为什么做这个平台

运动人体科学的知识分散在生理学教材、临床指南、训练实践与大量原始文献之间，初学者往往只能获得结论而看不到证据链。本站尝试把「文献证据 — 生理机制 — 评估工具 — 训练决策」串成一条可操作的路径：每个结论都有出处，每个模型都可调参数，每个工具都能复算。

目标不是替代教科书或临床指南，而是提供一个结构化的索引与演练场，让本科生能练习检索、分级、建模与批判性阅读。

内容边界
  • 不做泛科普与商业种草，不推荐具体品牌或购买渠道
  • 不提供个体化医疗诊断、处方或康复方案
  • 不收录未公开数据、不抓取付费数据库全文
  • 文献条目为学习性摘编，结论以原始出版物为准
  • 模型为经典公式的教学化简化实现，存在适用边界
  • 竞技禁用物质仅作规则说明，不提供获取或使用指导

TECHNICAL

技术架构

纯静态 · 零后端

全部页面为静态 HTML/CSS/JS，无服务器、无数据库、无账号系统。可直接双击本地打开，也可托管于任意静态站点服务。

本地计算

剂量计算、风险评估、Meta 分析、计划生成全部在浏览器内完成；输入数据不上传、不存储、不离开本机。

离线依赖

Three.js 与 Apache ECharts 以本地 UMD 文件随站点分发，不依赖 CDN 与外网请求，断网仍可完整使用。

可视化引擎

背景星域与首页三维图形由 Three.js 绘制；证据分布、活动度、负荷曲线等图表由 ECharts 渲染，统一使用自建暗色主题。

模型实现

心肺一阶动力学、Banister 疲劳-适应、一房室药代、能量平衡等模型均以显式公式逐步积分实现，参数区间来自公开文献。

可访问性与适配

响应式布局覆盖桌面与移动端；遵循减少动态效果偏好；关键交互保留键盘可操作路径。
