# SPORTSCI RESEARCH INSTITUTE · 运动科学全域智能科研平台

一个**纯静态**的运动人体科学科研学习平台，涵盖证据检索、生理仿真、风险评估、补剂循证、人体图谱、临床运动处方与训练计划生成，全部计算在浏览器本地完成，零后端、零跟踪。

## 技术栈

- 纯 HTML / CSS / JavaScript，无构建工具
- 本地 UMD 依赖：`vendor/three.min.js`（3D 星域背景 + 人体解剖线框）、`vendor/echarts.min.js`（可视化图表）
- 所有计算（剂量、评估、Meta 分析、计划生成）在浏览器内完成，数据不上传

## 本地运行

直接双击 `index.html` 即可在浏览器打开（推荐 Chrome / Edge）。

如需本地服务器：

```bash
# Python 3
python -m http.server 8000

# 或 Node
npx serve .
```

然后访问 http://localhost:8000

## 部署到 GitHub Pages

1. 将本仓库推送到 GitHub
2. 仓库 Settings → Pages → Source 选 `main` 分支、`/ (root)` 目录
3. 等待部署完成后访问 `https://<用户名>.github.io/<仓库名>/`
